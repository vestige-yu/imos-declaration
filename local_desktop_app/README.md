# 报表处理工具客户使用说明

## 打开程序

双击 `报表处理工具.exe`。程序会打开本机浏览器页面，首页提供两个独立入口：

- `报关单生成`：上传 Invoice 和 Packing list，预览后生成报关单。
- `报表合并`：上传 1～30 份源报表，预览后生成合并结果。

程序只在当前 Windows 电脑本机运行，不会把文件上传到外部服务器。

## 配置维护

两个功能各自有“规则与模板”页签，共有四类独立配置：

1. 报关单生成模板。
2. 报关单匹配规则。
3. 报表合并生成模板。
4. 报表合并规则。

客户包中的配置文件是维护参考和初始资料。修改后，需要在对应功能的“规则与模板”页签重新上传并启用。程序不会自动读取 EXE 旁边被替换的文件。

上传新配置时，程序会先验证文件；验证通过才启用，并保留本机版本副本。四类文件分别保存，互不覆盖。

## 历史记录

两个功能分别保存自己的历史记录：

- 最近记录只显示最近 5 条，可逐条删除。
- 历史查询支持按开始时间和结束时间筛选。
- 每页最多显示 50 条，可翻页。
- 报关单历史可下载当时的 Invoice、Packing、预览和报关单。
- 合并历史可下载源报表、当时使用的模板和规则、预览和合并结果。

删除历史记录时，会同时删除该记录保存在本机的文件。

## Windows 数据位置

报关单生成数据：

```text
%LOCALAPPDATA%\SuriWorkDeclaration\
```

报表合并数据：

```text
%LOCALAPPDATA%\SuriWorkReportMerge\
```

两套数据目录相互独立。误删其中一套配置不会影响另一个功能，但对应功能会恢复使用 EXE 内置的默认配置。

## 客户包内容

- `报表处理工具.exe`
- `报关单配置资料\`
- `报表合并配置资料\`

业务规则以客户包内最新说明文档为准。
